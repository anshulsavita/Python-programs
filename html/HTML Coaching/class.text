<form></form>
bind the data in single unit
attributes
- action= any_url
 will move the control to specified URL when user click on submit button

- method=get/post/put/patch/delete

get 
will show the input information on address bar 

post
will not show the information on address bar

validations
----------
regex(regular expression)
required
[A-Z] will allow only one character in uppercase
[A-Z a-z] 
 will allow only one character in uppercase/lowecase/space
[A-Z a-z] +
 will allow n character in uppercase/lowecase/space
[A-Z a-z]{20}
allow fixed 20 characters
[0-9A-Za-z]{16}
[A-Z a-z]{5,20} min 5 max 20
[A-Z a-z]{5,} min 5 max n
[A-Z a-z]{,20} min 0 max 20
[0-9]{10}
